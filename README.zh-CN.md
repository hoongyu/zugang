# Zugang

**一个免费、可离线使用的自查工具：告诉国际申请人是否满足德国硕士专业的入学要求，并为每个答案显示规则、计算过程和来源，提供英文和简体中文。**

*Zugang* 意为“通道”，如 *Hochschulzugang*（高等教育入学）。为 AccessED Hacks 2026 制作。主赛道：**Afford**；同时服务 **Understand**。

## 解决什么障碍

从国外申请德国硕士，需要在许多官方网页（多为德语）中自行理解：成绩换算成德国分制、各学科领域按 ECTS 计算的最低学分、中国/印度/越南学历需要的 APS 证书，以及 uni-assist 的费用和期限。很多人因此花钱找中介，或为本来就不符合条件的专业支付 uni-assist 费用。

- **费用**：无需中介即可完成初步自查，不会把 uni-assist 费用花在不符合条件的专业上。
- **语言**：用通俗的英文和中文解释德语录取术语，并保留德语原词，例如“申请截止日期（Bewerbungsfrist）”。

## 前后对比：Lin（虚构的示例申请人）

Lin 在中国读了 4 年本科：百分制，最低及格 60 分，平均 85 分，共 160 学分，其中数学 20 学分、计算机科学 70 学分，雅思 6.5。目标：示例专业“数据科学硕士”（最低成绩 2.5，数学至少 36 ECTS，通过 uni-assist 申请，截止日期 2027-07-15）。

- **之前**：Lin 付钱找中介，或读了十几个德语网页仍不确定。
- **之后**：一个页面，每个数字都有解释和来源（以下数值由代码计算，并由 `tests/check.test.js` 断言）：
  - 德国成绩 **2.125**（1 + 3 × (100 − 85) / (100 − 60)），满足 2.5。
  - 每个学分约合 **1.5** ECTS（4 × 60 / 160），数学为 **30 ECTS，比 36 少 6**。
  - **需要 APS 证书**：现在就开始办理。
  - uni-assist 申请和缴费最好在 **2027-05-20** 前完成（截止日期前 8 周）。
  - uni-assist 费用：1 个专业 **75 欧元**，2 个专业 **105 欧元**。

## 如何运行

```sh
git clone https://github.com/hoongyu/zugang.git
cd zugang
python3 -m http.server 8000
```

打开 http://localhost:8000/ 。在地址后加 `?example=lin` 可直接查看 Lin 的结果。测试：`node --test`（Node 18 及以上，无依赖）。

## 局限

各大学规则不同，请务必查看目标专业的官方网页；成绩公式仅供参考；ECTS 换算是估算；APS 和语言考试费用不显示，以各 APS 审核部和考试机构公布的为准；换算成绩截断还是四舍五入只部分核实（KMK 协议只对中学毕业证书规定截断）；不构成法律建议；与 uni-assist、DAAD、APS 及任何大学均无关联。
