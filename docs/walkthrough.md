# Walkthrough script (2 to 3 minutes)

Record the browser at 1280 px width, page zoom 125% so text is readable. Serve with `python3 -m http.server 8000`. Short sentences below are ready to use as captions.

| Time | On screen | Say / caption |
|---|---|---|
| 0:00 | http://localhost:8000/ , top of page | This is Zugang. It checks if you can apply to a German master's programme. |
| 0:08 | Point at the privacy line | It is free. It works offline. Nothing you type leaves your browser. |
| 0:15 | — | Many applicants pay agencies for this. Or they pay application fees for programmes they never qualified for. |
| 0:25 | Example applicant: choose "Lin", press "Load example" | Lin is an invented applicant from China. |
| 0:32 | Scroll through the filled form | A 100-point scale, average 85. 160 credits, 20 in mathematics. IELTS 6.5. |
| 0:42 | Programme: "M.Sc. Data Science (example)" | The target is an invented data science programme. |
| 0:48 | Press "Check my eligibility" | One click. |
| 0:52 | Grade card | Lin's German grade is 2.125. Lower is better, so it meets 2.5. |
| 1:00 | Point at the calculation and the warnings | You see the formula, the numbers, and the warnings. The result is orientation only. |
| 1:10 | Point at "cut" and "rounded" | We found no rounding rule for degrees, so we show both values. |
| 1:18 | ECTS card | Four years are 240 ECTS. So one credit is about 1.5 ECTS. |
| 1:26 | Mathematics card, red "Not met" | Mathematics comes to 30 ECTS. The programme wants 36. Lin is 6 short. |
| 1:34 | Next step line | The next step: check the module handbook, or take extra courses. |
| 1:42 | Source line with "verified" | Every result links its source and says how well it is verified. |
| 1:50 | Timeline | Lin needs an APS certificate. Start now. The uni-assist application should go in by 20 May 2027. |
| 2:00 | Fees | uni-assist costs 75 euros for one programme, 105 for two. Lin knows the gap before paying. |
| 2:10 | Press "中文" | Everything is also in Simplified Chinese. German terms stay next to the translation. |
| 2:18 | Glossary, type "Frist" in the filter | The glossary explains 27 German admission terms. |
| 2:26 | Press Tab a few times, show the focus outline | It works with the keyboard only, with screen readers, and on small phones. |
| 2:35 | Press "Download as Markdown" | You can print or save your results. |
| 2:42 | Footer | Not legal advice. Always check your programme's official page. Thank you. |

Total: about 2 minutes 45 seconds. Captions: export the "Say" column as an SRT file, or use the platform's auto-captions and correct them.
